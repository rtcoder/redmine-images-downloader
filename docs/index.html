Features

Everything you need,
nothing you don't

A focused tool that does one thing well — no configuration, no sign-in, no bloat.

🔍

Auto-detection

Recognises Redmine pages automatically — works on any self-hosted or cloud Redmine instance.

⚡

One-click batch download

A single "Download all" button appears next to each album. Click once, get everything.

📁

Original filenames

Files land in your Downloads folder with their original names — no random strings, no renaming needed.

🔗

Smart URL handling

Resolves relative URLs and strips duplicates automatically before starting downloads.

🔒

Minimal permissions

Only the downloads permission — no access to your data, no telemetry.

🆓

Free & open source

MIT licensed. Inspect the code, fork it, contribute — it's all on GitHub.

How it works

Three steps. Zero friction.

1

Install

Add the extension to Chrome from GitHub or the Chrome Web Store.

2

Open a Redmine issue

Navigate to any Redmine issue or page that contains image attachments.

3

Click "Download all"

The button appears automatically next to each image album. Click it and all images download instantly.
